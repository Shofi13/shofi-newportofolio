Student Payment System

A web-based school payment management system developed during my internship at SDI Nurul Ulum to simplify student payment administration and reporting.

Role Full Stack Developer (Intern)
Tech Stack Laravel · PHP · MySQL
Period Jan – Mar 2026

Project Overview

This system was developed to help school administrators manage student payment records efficiently. It centralizes student data, billing, payment transactions, financial reports, and receipt generation into one web application.

My Contribution

Backend

Developed application features using Laravel and PHP.

Database

Designed and managed MySQL database integration.

Frontend

Built responsive interfaces using Bootstrap.

Workflow

Implemented payment flow, reporting, and receipt printing.

Student Data Billing Payment Reports Receipt Printing Admin Dashboard
